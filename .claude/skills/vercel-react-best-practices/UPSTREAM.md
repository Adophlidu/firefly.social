## Updating

To re-sync from upstream:

1. Fetch the latest `skills/react-best-practices/` directory from the upstream repo at the desired tag/commit.
2. Replace `SKILL.md` (re-applying the one local edit: the "Full Rule Set" section instead of "Full Compiled Document").
3. Replace the `rules/` directory wholesale.
4. Update the snapshot commit + date above.
5. Do NOT bring `AGENTS.md`, `README.md`, `metadata.json`, or `.skillshare-meta.json` — those are intentionally excluded.
