# Firefly i18n (Lingui + Tolgee)

> **Authoritative source for i18n workflow.** CLAUDE.md only lists the macro imports; this file is the canonical reference.

Detailed guide for internationalization in `apps/web`.

## Stack

- **Lingui** — extraction + compilation
- **Tolgee** — translation management (https://i18n.firefly.land, project ID 4)
- **Locales**: `en` (source), `es`, `ko`, `ja`, `zh-Hans`, `zh-Hant`
- **Compiled files**: `src/locales/{locale}/messages.ts` — auto-generated, NEVER edit manually

## When to Run

`pnpm lingui` is run automatically by GitHub CI after each commit — no need to run it locally. The command runs: `lingui:extract → lingui:compile → lingui:regenerate-gettext-plural-metadata`.

## Imports

```ts
import { Trans } from '@lingui/react/macro'; // JSX components
import { t, plural } from '@lingui/core/macro'; // JS strings + plurals
```

❌ NEVER import from `@lingui/macro` (wrong package for this project)

## Usage Patterns

**Static text (JSX):**

```tsx
<Trans>My Accounts</Trans>
```

**With variables (JSX):**

```tsx
<Trans>Settled as {resolvedOutcome.outcome}</Trans>
```

**JS string (non-JSX context):**

```ts
const label = t`Failed to load posts`;
```

**Plural:**

```ts
import { plural } from '@lingui/core/macro';

const text = plural(count, {
    one: '# minute',
    other: '# minutes',
});
```

**Trans with nested React components** (use slot pattern):

```tsx
<Trans>
    Read our <a href="/terms">Terms of Service</a>
</Trans>
```

## File Locations

- Source catalog: `src/locales/en/messages.po` — reference only
- Compiled: `src/locales/{locale}/messages.ts` — auto-generated
- Config: `apps/web/lingui.config.js`
- Tolgee config: `apps/web/.tolgeerc.json`

## Tolgee Sync

Translations are managed in Tolgee. Do NOT manually edit non-English `.po` files.

```bash
# Pull latest translations from Tolgee (also runs lingui:extract + lingui:compile)
pnpm tolgee:sync

# Push new English source strings to Tolgee
pnpm tolgee:push-sources
```

## Scope Coverage

Lingui scans these directories (from `lingui.config.js`):
`app`, `configs`, `components`, `constants`, `connectors`, `helpers`, `hooks`, `providers`, `modals`, `store`, `services`, `mask`

Strings in files outside this list will NOT be extracted.
