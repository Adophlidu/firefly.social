# Firefly i18n (Lingui + Tolgee)

> **Authoritative source for i18n workflow.** CLAUDE.md only lists the macro imports; this file is the canonical reference.

Detailed guide for internationalization in `apps/web`.

## Stack

- **Lingui** — extraction + compilation
- **Tolgee** — translation management (https://i18n.firefly.land, project ID 4)
- **Locales**: `en` (source), `es`, `ko`, `ja`, `zh-Hans`, `zh-Hant`
- **Compiled files**: `src/locales/{locale}/messages.ts` — auto-generated, NEVER edit manually

## When to Run

`pnpm lingui` is run automatically by GitHub CI after each commit — no need to run it locally. The command runs: `lingui:extract → lingui:compile → lingui:regenerate-gettext-plural-metadata`.

## Imports

```ts
import { Trans } from '@lingui/react/macro'; // JSX components
import { t, plural } from '@lingui/core/macro'; // JS strings + plurals
```

❌ NEVER import from `@lingui/macro` (wrong package for this project)

## Usage Patterns

**Static text (JSX):**

```tsx
<Trans>My Accounts</Trans>
```

**With variables (JSX):**

```tsx
<Trans>Settled as {resolvedOutcome.outcome}</Trans>
```

**JS string (non-JSX context):**

```ts
const label = t`Failed to load posts`;
```

**Plural:**

```ts
import { plural } from '@lingui/core/macro';

const text = plural(count, {
    one: '# minute',
    other: '# minutes',
});
```

**Trans with nested React components** (use slot pattern):

```tsx
<Trans>
    Read our <a href="/terms">Terms of Service</a>
</Trans>
```

## File Locations

- Source catalog: `src/locales/en/messages.po` — reference only
- Compiled: `src/locales/{locale}/messages.ts` — auto-generated
- Config: `apps/web/lingui.config.js`
- Tolgee config: `apps/web/.tolgeerc.json`

## Tolgee Sync

Translations are managed in Tolgee. Do NOT manually edit non-English `.po` files.

```bash
# Pull latest translations from Tolgee (also runs lingui:extract + lingui:compile)
pnpm tolgee:sync

# Push new English source strings to Tolgee
pnpm tolgee:push-sources
```

## Translating With Context

Many source strings are short, ambiguous English words whose meaning depends on UI context. Always translate the **meaning in place**, not the dictionary definition. Before translating a string, open the component that uses it and confirm what the action/label actually does.

**Cross-reference existing catalogs first.** For any ambiguous source string, grep the other locale `messages.po` files to see how the same `msgid` is already rendered — another language's existing translation often disambiguates the intended sense, and keeps terminology consistent across locales. Also check sibling keys on the same UI surface (same button/menu/component) so the wording matches — e.g. an `unmute-wallet` key must agree with the `Mute` / `Muted` keys that sit next to it on the same button.

### Known ambiguity traps (real bugs we have hit)

| Source | Trap (wrong sense) | Correct sense in this app |
| --- | --- | --- |
| `Draw` | "to draw/paint" — es was wrongly *dibujar* | prediction-market **tie** — es *empate* |
| `Quote` | price **quotation** | social **quote-post** (key `action-quote`, es *citar*) |
| `Unmute` | audio **unmute** | **unblock** a wallet/user (key `unmute-wallet`) |
| `Block` | blockchain **block** | **block** a user |
| `Tip` | **hint / advice** | crypto **tip / gratuity** |
| `Shares` | social **sharing** | trading **position / holding** |
| `Props` | component **props** | prediction-market **proposition bet** |
| `Recast` | literal "cast again" | Farcaster **repost** |

### When one word has two coexisting meanings in the app

Split it into independent keys with an explicit `id` and a `comment`, so each sense gets its own translation instead of colliding on a single `msgid`:

```tsx
// Compose dialog title — a social quote-post, NOT a price quote
<Trans id="action-quote" comment="Compose dialog title: a social quote-post (not a price quote)">
    Quote
</Trans>

// Wallet unblock — social, NOT audio
<Trans id="unmute-wallet" comment="Unmute (unblock) a wallet — social, not audio">
    Unmute
</Trans>
```

Reference: PR #9386 (FW-7854) corrected the `es` catalog after several wrong-sense translations slipped in, and split `Quote` / `Unmute` this way.

## Scope Coverage

Lingui scans these directories (from `lingui.config.js`):
`app`, `configs`, `components`, `constants`, `connectors`, `helpers`, `hooks`, `providers`, `modals`, `store`, `services`, `mask`

Strings in files outside this list will NOT be extracted.
