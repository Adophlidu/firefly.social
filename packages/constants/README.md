# @dimensiondev/constants

Shared constants used across Firefly packages and apps.

| Export                             | Module     | Contents                                         |
| ---------------------------------- | ---------- | ------------------------------------------------ |
| `@dimensiondev/constants`          | `runtime`  | `EMPTY_LIST`, `EMPTY_OBJECT`, `IS_PRODUCTION`, … |
| `@dimensiondev/constants/static`   | `static`   | URLs, contract addresses, limits, site metadata  |
| `@dimensiondev/constants/computed` | `computed` | Source lists and enums-derived configuration     |
